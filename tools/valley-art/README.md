# Valley art workflow memory

Use `assets/source/voxel/valley-onboarding/inventory.json` for the selected sources, native revisions, pitch, pivots, models and editable part groups. Lead owns runtime binding, bake and shared Blender MCP. New art stays in this source tree; no production bake from this toolset.

Generated standalone props: preserve original PNG/prompt/brief → installed local TRELLIS → native VOX → inspect real openings/volume/unlit colors → explicit preserved correction if needed. Buildings and planted flowers/saplings use approved original exact native modules. `native-audit.json` records source checks; art approval remains separate.

`run_batch.py` reuses the nearest existing host runtime without modifying it. `capture.mjs asset job` independently loads local VOX/GLB and captures browser views; serialize GPU work with lead benchmarks. `software_iso.py asset job` is CPU-only exact cell-face inspection with the unchanged actor at shared scale. `review_blender.py` is a lead-only MCP recipe.

`author_action_pixels.py` writes the original shield and native windup/contact/recovery recipes. Preserve the32×32 canvas,17×18body, foot(16,28), shared6.25cm pitch and hand/tool grip. No body redesign, per-tool fitting or visual authority over gameplay.

Raw learned NPZ/PLY/GLB and Blender review sources remain local and are ignored in this source tree. Keep editable VOX, exact prompts, provenance, reports and actual review images in the repository. No paid endpoint, key or external runtime call is required.
