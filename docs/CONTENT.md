# Vertical Slice Content

World: Oakrest village, forest, copper/tin mine, bank, furnace, anvil. Data-driven navigation and resource nodes. Skills: Woodcutting, Mining, Smithing, each with XP table and level requirements. Items: basic axe, pickaxe, logs, copper ore, tin ore, bronze bar, bronze sword, coins. 28-slot inventory, bank storage. Recipes: copper+tin at furnace -> bronze bar; bronze bars at anvil -> bronze sword. Starting tools explicitly granted. All action times and XP configurable integer ticks. NPC professions include gatherer, miner, smith, trader. Thought triggers: inventory milestone, level unlock, goal complete, route inefficiency, resource shortage, new opportunity. No combat required for first slice.

## Current demo content override
