# Ground foliage and wind

The 3D world now has original grass, woodland ferns, pale flowers and shoreline reeds. Native editable VOX sources live in `assets/source/voxel/ground-foliage-v1/`, at the scenery's 0.0625m cubic pitch. Vite inlines their exact native bytes; the existing parser derives exposed cell faces. There are no runtime texture/model requests, new dependencies or services.

Placement reads the renderer's presentation terrain: grass supports meadow clumps, nearby trees seed woodland, and dry grass/sand beside water supports reeds. Connected dirt/paving and their margins stay clear. Object footprints plus service/entrance margins, tree trunks, crops, fences and collision cells are excluded. Large empty patches and denser patches come from coordinate hashes. Roots snap to native voxel-cell centres and rotations use only 90° turns, keeping cubic faces aligned with the scenery. The presentation cleanup of isolated dirt speckles does not change logical tiles.

A shared shader wind field moves upper vertices with travelling gusts while displacement is exactly zero at ground height. Native shapes remain editable. Wind is cosmetic, independent of gameplay RNG, 600ms ticks, navigation, saves and resource availability. Reduced motion straightens plants; wind strength zero stops motion. This pass does not animate tree crowns, add actor-push interaction or implement fog.

Visual settings → Vegetation exposes enable, density and wind strength. Defaults: enabled, 0.7 density, 1× wind. These preferences persist on the device, copy with presets and reset with visual settings; older settings acquire defaults. Density removes stable ranked plants before upload, reducing submitted clumps as well as visible coverage.

Four shared clump meshes use GPU instancing, opaque materials, normal world lighting, received sun shadows and sampled GI. Character bodies and held layers use their ground pivot's projected depth. Foliage uses each voxel column's ground support position, preserving its horizontal footprint instead of collapsing the entire clump to one point. This keeps bases above opaque terrain while preventing tall tips behind a character from slicing its body. A two-unit raster depth offset resolves coplanar rounding at long camera distances without moving geometry. Visible vertex positions and world-lighting coordinates are retained. This stylized sorting applies in perspective, orthographic and reflected views; it is not physical per-face foliage depth. Foliage does not cast shadows or enter the static GI occluder/bounce capture. Fewer plants remain toward 28m; the overview hides them. A bounded local window uploads only when the target crosses an 8m region, density changes or the world layout changes. Main and water-reflection cameras share these instances. Wind only updates uniforms each frame; diagnostic counts update at 2Hz.

Limits: four small art drafts, flat-world grounding, whole-clump distance thinning and approximate bent-face normals. No full-world vegetation persistence or dynamic foliage shadows/GI rebuilds. Real raised terrain will need the shared ground-height sampler before integration. Physical-phone performance remains unmeasured.

Browser evidence and visual review: [foliage-v1](art-audit/foliage-v1/README.md). Copy performance includes foliage plant counts, uploads and wind time.
